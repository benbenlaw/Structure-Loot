Changelog BBL Structure Loot

# 1.2.0
- Added WIP JEI support, should show most loot that will spawn from the tokens
- Some items may be missing from the JEI category, but the loot (if it does spawn from the selected loot table) will always generate in the Structure Generator
- Changed the recipe to use obtained_chance instead of can_be_obtained. The default for this is now 0.1 for most entities and structures. Blocks are 0.01
- Enabled config to disable token drops for each token type; by default, structures are on, entities and blocks are off
- Entity loot tables no longer parse the player (fake player) as the killer unless theres a item inside the bottoms slot
- The bottom slot now acts as the main hand item for the Loot Generator 
- This slot, when containing an enchanted item, will apply the enchantments to the loot generated, eg fortune pickaxe will apply the fortune enchantment to the block token
- Having a Luck Potion inside this slow will apply the luck effect to the token loot

# 1.1.5
- Fixed "crash" / freeze when shift clicking a token when a token is already present in the Loot Generator 
- Entity loot now parses the player (fake player) as the killer which allows for drops like blaze rods from blazes 
- Tokens now show the id in the name to make it easier to find in the token you want in JEI 
- Added most minecraft entities token

# 1.1.4
- Fixed handler interactions
- Fixed items going into an un seen slot

# 1.1.3

# 1.1.2

# 1.1.1

# 1.1.0
- Renamed the mod to BBL Loot Generator
- Tweaked recipes, structure is now loot_id
- Recipes can now have an optional max_durability field which sets the max durability of the token
- Now supports blocks and entities
- Any blocks/entities added will add the token to jei and creative as well as be a drop from the block/entity when holding the token charm
- Token Charm support Curio mod
- Block and Entity token require the Token Hunter enchantment to be on the tool to obtain
